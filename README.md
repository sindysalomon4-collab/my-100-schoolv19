# My 100 School

Clean rebuild of the My 100 School student portal.

## Current foundation
- Student sign-in/demo mode
- Dashboard
- Classes
- Assignments
- Grades
- Attendance
- SQLite schema for students, classes, assignments, grades and attendance

## Run locally
npm install
npm run dev

## Build
npm run build

## Android
The web foundation is ready to be wrapped with Capacitor using package ID `com.my100school.app`.
