# My 100 School — Android setup

Package ID: `com.my100school.app`

## Build the Android project

On a computer with Node.js and Android Studio:

1. `npm install`
2. `npm run android:add`
3. `npm run android:sync`
4. `npm run android:open`
5. In Android Studio choose **Build > Build APK(s)**.

The original v19 source was not available in full, so this is the clean rebuild foundation with the current student portal features.
